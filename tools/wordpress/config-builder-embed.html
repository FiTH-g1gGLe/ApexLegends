Install it

      
    
        
  1. Close Apex Legends completely.
    2. 
        
  2. Press Win + R, paste %USERPROFILE%\Saved Games\Respawn\Apex\local and press Enter.
    3. 
        
  3. Copy your current videoconfig.txt somewhere safe as a backup.
    4. 
        
  4. Replace it with the downloaded file. The name must stay exactly videoconfig.txt.
    5. 
        
  5. Launch the game and play. Don't open the video settings menu, because saving anything there rewrites the file with menu values.
    6. 
      

    

    

      
Good to know

      
    
        
  • The file survives restarts on its own. Only set it to read-only if the game keeps changing it back.
    • 
        
  • To undo everything, put your backup back, or delete the file and the game creates a fresh one.
    • 
        
  • Settings marked file only can't be reached from the in-game menu at all.
    • 
        
  • Settings marked untested are written correctly but their in-game effect hasn't been confirmed yet.
