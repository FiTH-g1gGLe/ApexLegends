# Legacy configs

The Season 21 configs (2024) are kept here for reference. **Don't use them as they are**: the videoconfig is format version 8 (the game is now on version 10), and most of the autoexec commands are blocked or don't exist in Apex. See [docs/file-format-history.md](../docs/file-format-history.md) and [docs/autoexec.md](../docs/autoexec.md).

Use the files in [`configs/`](../configs) or the [config builder](../tools/config-builder.html) instead.
